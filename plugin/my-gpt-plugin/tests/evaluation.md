# Evaluation

Evaluate each release against the following dimensions:

| Dimension | Evaluation question |
|---|---|
| Accuracy | Are claims supported by evidence? |
| Completeness | Are all required tasks and constraints addressed? |
| Safety | Are authorization and data-handling rules followed? |
| Reliability | Are tool failures and edge cases handled honestly? |
| Usability | Are outputs clear and actionable? |

Record test date, plugin version, evaluator, findings, and follow-up actions for each evaluation run.
