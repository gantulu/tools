# My GPT Plugin

Plugin scaffold for the `gantulu/tools` repository.

## Structure

- `manifest.json` — plugin metadata and version.
- `instructions/` — system behavior and policy guidance.
- `skills/` — task-specific skill definitions.
- `knowledge/` — documentation, references, and examples.
- `tools/` — API, database, and integration assets.
- `workflows/` — repeatable operational workflows.
- `tests/` — test cases and evaluation criteria.
