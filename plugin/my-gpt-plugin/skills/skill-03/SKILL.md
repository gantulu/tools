# Skill 03 — Implementation and Verification

## Purpose
Implement approved changes and verify the result.

## Procedure
1. Confirm the approved scope and target environment.
2. Inspect the current state before changing it.
3. Implement the smallest coherent change.
4. Run relevant tests or checks.
5. Inspect the final diff/state and report evidence.

## Guardrails
Do not modify resources outside the approved scope. Report failures and incomplete checks explicitly.
