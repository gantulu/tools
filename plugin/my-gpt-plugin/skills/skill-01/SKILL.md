# Skill 01 — Requirement Analysis

## Purpose
Convert a user request into clear, testable requirements.

## Procedure
1. Identify the intended outcome and scope.
2. Record constraints, dependencies, and assumptions.
3. Identify unresolved decisions.
4. Propose acceptance criteria.
5. Obtain approval before implementation when changes are involved.

## Output
A concise requirement brief with scope, decisions, open questions, and acceptance criteria.
